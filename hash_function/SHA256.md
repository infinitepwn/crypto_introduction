# SHA-256

SHA-256 是 SHA-2 家族中的一种密码哈希函数，输出长度为 256 bit。它常用于完整性校验、数字签名、区块链工作量证明和密钥派生等场景。

## 输入输出

- 输入：任意长度的比特串。
- 输出：固定长度的 256 bit 摘要。
- 目标性质：抗原像、抗第二原像、抗碰撞。

## 与[[MD结构]]的关系

SHA-256 采用 Merkle-Damgård 思路：

1. 对消息进行填充，使其长度满足分组要求。
2. 将消息切分为 512 bit 分组。
3. 用压缩函数逐组更新内部状态。
4. 输出最终 256 bit 状态作为摘要。

## 填充规则

设原消息长度为 $l$ bit：

1. 先追加一个 `1`。
2. 再追加若干个 `0`，使长度同余于 $448 \pmod{512}$。
3. 最后追加 64 bit 的原消息长度编码。

这种长度填充能让不同长度的消息边界清晰，避免简单拼接歧义。

## 核心压缩过程

每个 512 bit 分组会扩展为 64 个 32 bit 字。压缩函数使用加法、异或、循环移位、选择函数和多数函数迭代更新 8 个 32 bit 工作变量。

常见记号：

- `Ch(x,y,z) = (x ∧ y) ⊕ (¬x ∧ z)`：按 `x` 选择 `y` 或 `z`。
- `Maj(x,y,z) = (x ∧ y) ⊕ (x ∧ z) ⊕ (y ∧ z)`：多数函数。
- `Σ0, Σ1, σ0, σ1`：由循环右移和右移组成的扩散函数。

## 在比特币中的作用

比特币工作量证明可以理解为寻找一个随机数，使区块头的双 SHA-256 哈希值小于目标难度值。这里依赖的不是加密保密性，而是哈希函数的原像搜索困难性。
