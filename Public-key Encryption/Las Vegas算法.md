# Las Vegas 算法

Las Vegas 算法是一类随机算法：运行时间可能随机变化，但只要输出结果，结果一定正确。

## 与 Monte Carlo 算法的区别

- Las Vegas 算法：结果一定正确，运行时间不确定。
- Monte Carlo 算法：运行时间通常固定或可控，但结果可能有小概率错误。

## 密码学中的意义

密码学经常使用随机性，但不同算法对错误概率的要求不同。例如：

- 随机化算法可以用于寻找因子、生成参数或选择候选值。
- 如果算法必须保证结果正确，就更接近 Las Vegas 思路。
- 如果允许极小错误概率，例如部分素性测试，则更接近 Monte Carlo 思路。

## 学习要点

判断一个随机算法时，先问两个问题：

1. 它会不会输出错误答案？
2. 它的运行时间是否可能依赖随机选择？

如果答案是“不会输出错误答案，但运行时间随机”，就是 Las Vegas 算法。
