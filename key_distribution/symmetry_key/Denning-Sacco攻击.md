# Denning-Sacco 攻击

Denning-Sacco 攻击说明：只靠加密发送旧会话密钥并不能保证协议安全。如果旧会话密钥泄露，攻击者可能重放旧票据，让接收方误以为正在建立新会话。

## 攻击思路

在某些基于票据的密钥分发协议中，服务器会把会话密钥和身份信息加密后交给通信方。如果攻击者保存了旧票据，并在后来获得旧会话密钥，就可能重放旧消息来冒充一方。

## 根本原因

- 票据缺少足够的新鲜性保证。
- 会话密钥泄露后，旧会话消息仍可能被接受。
- 协议没有把时间戳、随机数或有效期检查设计得足够严格。

## 防护思路

- 在票据中加入时间戳和有效期。
- 使用挑战-响应证明当前仍掌握密钥。
- 明确绑定通信双方身份和会话上下文。

[[Kerberos-V5]]通过票据有效期和时间戳机制缓解这类重放风险。
