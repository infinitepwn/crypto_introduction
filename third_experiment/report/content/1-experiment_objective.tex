本次实验的目的是理解并实现针对 CBC 工作模式下 PKCS\#7 填充机制的 Padding Oracle 攻击。通过实验，掌握在未知 AES 密钥的情况下，如何利用解密服务器对填充是否合法的反馈信息，逐字节恢复密文对应的明文。

具体而言，本实验需要完成以下目标：

\begin{enumerate}
    \item 理解 AES-128-CBC 模式的加解密结构，明确明文分组、密文分组和初始向量 IV 之间的关系；
    \item 掌握 PKCS\#7 填充规则，理解填充合法性判断如何泄露明文相关信息；
    \item 编写 Padding Oracle 攻击程序，利用服务器返回的填充状态恢复 CBC 解密过程中的中间状态；
    \item 对本小组抽到的 5 号密文进行破解，得到完整明文；
    \item 通过实验分析 CBC 模式在缺少完整性保护时可能产生的安全风险，加深对“加密不等于认证”的理解。
\end{enumerate}
