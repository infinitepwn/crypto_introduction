# 3D-Secure

SET 协议落地失败后，VISA 在 2003 年左右推动 3D-Secure 作为新的在线支付认证标准。

## 特点

- 优势：设计简化，应用更广。
- 目标：认证持卡人，降低盗刷风险。
- 问题：商家仍可能得到支付卡相关信息；协议依赖 SSL/TLS，缺乏消息层面的端到端保障。

## 部署层次

在网络的每一层都能部署，但是越底层，泄露的信息越多，因为加密的同时把协议的头部也加密了，传输过程中，必然在节点被解密

## 与[[SET协议]]的区别

SET 更强调在商户、支付网关和银行之间用证书、签名与加密保护订单和支付信息。3D-Secure 更像是在现有银行卡支付流程中增加一道身份认证层，落地成本较低，因此实际应用更广。
